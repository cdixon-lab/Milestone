## Accessibility

- Added descriptive alt text to images.
- Added labels, a fieldset, and a legend to the contact form.
- Added an accessible error message using aria-live.
- Checked the website using the WAVE accessibility tool and corrected any issues found.
## Visual Design

- I used the Gestalt principle of proximity by grouping related information into cards and sections.
- I used contrast with a consistent teal, white, and dark blue color palette to make the navigation and content easier to read.
